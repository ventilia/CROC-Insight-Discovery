# KIT · KROK insight tool

MVP платформы управления корпоративными отношениями: портфель клиентов, карточка компании, интерактивная карта ЛПР, профили сотрудников, история взаимодействий и аналитика охвата.

## Быстрый запуск

Нужен Node.js 22.13+:

```sh
cd frontend
npm ci
npm run build
npm run demo
```

Открыть [KIT на localhost](http://127.0.0.1:5173/). Демосервер автоматически загружает 10 компаний, 21 проект и 689 контактов в SQLite. В «Атлас Север» доступна карта из 540 участников и 1105 связей. Встречи и версии позиций сохраняются между перезапусками. База находится в `frontend/.data/` и не попадает в Git. Все исходные сведения синтетические.

## Что реализовано

- Обзор портфеля: компании, уникальные контакты, взаимодействия и зоны внимания.
- Карточка клиента: описание, подразделения, ключевые участники и история всех инициатив.
- Карта: роли обозначены цветом, явная оценка влияния влияет на размер, связи направленные, доступны окружение, масштаб и профиль человека.
- Профиль: контакты, роль и влияние с основанием, позиция, связи и история; отдельная подробная страница, окружение и переходы между проектами.
- Рабочие сценарии локального API: создание проекта и участника, уточнение карточки, добавление связи с основанием, черновики запросов, сравнение общих участников проектов.
- Тёмная и светлая темы: переключатель в верхней панели, выбор сохраняется в браузере. По умолчанию — тёмная палитра KIT.
- Меню с выбором компании и проекта; компактная карточка контакта с вкладками «О человеке», «Связи», «История» и переходом к следующему участнику. Структура адаптирована из предоставленных макетов.
- История: встречи, звонки, письма, комментарии и предложения. Сохранение участников, ответственного менеджера, результата и следующего шага.
- Поиск по платформе; фильтры карты и контактов по роли, отделу, должности, влиянию, касаниям и ответственному.
- Аналитика: прозрачный пилотный индекс и рекомендации по правилам. Локальный AI-навигатор подключается отдельно в Spring Boot.

Серверный вариант работает через Kotlin / Spring Boot / PostgreSQL и загружает ту же витрину в профиле `demo`. Для аналитики через ИИ запусти серверный вариант. Выбери локальную модель в интерфейсе или передай `OPENAI_API_KEY` бэкенду через окружение. Для правок подготовь деморедактора по инструкции бэкенда. Полная CRM-синхронизация — следующий этап.

## Проверки
