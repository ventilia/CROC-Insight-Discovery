# КРОК Insight · Демо карты связей

Самостоятельное демо карты ЛПР для обсуждения интерфейса. Основное React-приложение запускается по [инструкции команды](../README.md). Для запуска нужен Node.js 22 или новее. Устанавливать зависимости не нужно. Команды выполняются из `frontend/insight-preview/`.

```powershell
node server.mjs
```

Откройте [локальный сайт](http://127.0.0.1:4173). Остановка сервера — Ctrl+C. Для выбора другого порта задайте `CROC_FRONTEND_PORT` в окружении запуска.

В деморежиме используются обезличенные примеры ответов из `backend/examples` и расширенные вымышленные данные инициативы «Единая ИТ-платформа». Они позволяют проверить карту, поиск, фильтры, досье и связи проектов без подготовки базы.

## Работа с локальным API команды

1. Запустите backend в профиле `demo` по [его инструкции](../../backend/README.md).
2. В другом терминале, из `frontend/insight-preview/`, запустите прокси. Node читает настройки из локального файла бэкенда. Пароль используется только в процессе прокси и не передаётся в браузер.

   ```powershell
   node --env-file=../../backend/.env server.mjs --live
   ```

3. Откройте `http://127.0.0.1:4173`. В шапке появится метка «Локальный API» после загрузки. Адрес бэкенда — `127.0.0.1:8080`.

Режим API использует три GET-маршрута из [OpenAPI](../../backend/openapi.yaml): компании, инициативы, граф. Фильтры отдела и роли передаются параметрами запроса. Поиск и фильтр ЛПР работают в браузере. Когда API недоступен, интерфейс показывает сообщение и позволяет повторить запрос.

## Объём локального прототипа

- Карта связей, направленные рёбра, масштаб и перемещение, окружение контакта в один или два шага.
- Список участников, досье, общие участники инициатив, хронология и очередь запросов.
- Добавление участника, связи, касания и запроса, а также оценка отношений сохраняются в браузере отдельно для каждой инициативы и режима API.
- «Стратегия общения» предлагает шаги по локальным правилам для ролей, связей и касаний. Демо обращается к API чтения карты. Серверный «Навигатор» и правки тестового источника доступны в основном приложении команды.

Логику интерфейса можно найти в `app.mjs`, граф — в `graph.mjs`, запросы — в `api.mjs`, вымышленные данные — в `demo.mjs`. `server.mjs` выдаёт файлы фронтенда и проксирует готовые маршруты чтения только на локальный бэкенд.
