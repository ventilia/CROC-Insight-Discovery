# Интерфейс КРОК Insight

Экран открывается на детекторе потерянных связей. Он показывает охват инициативы, касания по подразделениям и дату проверки контактных данных. Из строки участника можно открыть последние события, а список к встрече копируется из текущей выборки.

1. Запусти API с профилем `demo` по [инструкции бэкенда](../backend/README.md).
2. Выполни из `frontend/` команды `npm ci` и `npm run dev`.
3. Открой [локальный интерфейс](http://127.0.0.1:5173/). Vite проксирует API на Spring Boot и читает пароль из локального `backend/.env` на стороне сервера.

Проверки запускаются командами `npm test` и `npm run build`. Для статической сборки нужен сервер, который маршрутизирует `/api` к бэкенду.

В карточке участника есть позиция и форма тестового источника. Для правки подключи [деморедактора](../backend/README.md#правка-в-тестовом-источнике). Vite использует его пароль только для маршрута источника. В режиме просмотра карточки и история остаются доступны.

«Навигатор» показывает состояние [локальной модели](../backend/README.md#локальный-навигатор) и отправляет вопрос о выбранной инициативе по нажатию «Спросить».
