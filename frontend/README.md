# Интерфейс КРОК Insight

Экран открывается на детекторе потерянных связей. Он показывает охват инициативы, касания по подразделениям и дату проверки контактных данных. Из строки участника можно открыть последние события, а список к встрече копируется из текущей выборки.

1. Запусти API с профилем `demo` по [инструкции бэкенда](../backend/README.md).
2. Выполни из `frontend/` команды `npm ci` и `npm run dev`.
3. Открой [локальный интерфейс](http://127.0.0.1:5173/). Vite проксирует API на Spring Boot и читает пароль из локального `backend/.env` на стороне сервера.

Проверки запускаются командами `npm test` и `npm run build`. Для статической сборки нужен сервер, который маршрутизирует `/api` к бэкенду.

В карточке участника есть позиция и форма тестового источника. Для правки подключи [деморедактора](../backend/README.md#правка-в-тестовом-источнике). Vite использует его пароль только для маршрута источника. В режиме просмотра карточки и история остаются доступны.

«Навигатор» показывает состояние [локальной модели](../backend/README.md#локальный-навигатор) и отправляет вопрос о выбранной инициативе по нажатию «Спросить».

## Карта влияния

В основном React-приложении переключись на «Карту влияния». Данные приходят из `GET /api/v1/initiatives/{initiativeId}/graph`. Поиск, роль и подразделение фильтруют полученный граф. Каталоги фильтров остаются полными даже при пустом результате. Стрелки сохраняют направление `source → target`, неподтверждённые связи показаны пунктиром. Описание и статус каждой видимой связи доступны также текстом под картой.

Для сценария из защиты выбери роль «Утверждает бюджет», открой Марину Орлову и нажми «Окружение выбранного». Окружение сбрасывает остальные фильтры и показывает прямые входящие и исходящие связи. Клик по человеку открывает существующую карточку с позицией, автором, историей и редактором тестового источника. Масштаб меняется кнопками, большая карта прокручивается, карточки доступны с клавиатуры.

## Индекс устойчивости отношений

Индекс рассчитывается по полному ответу `/coverage`, независимо от фильтров таблицы и карты. Это пилотный показатель охвата по зафиксированным данным, а не подтверждённая оценка доверия клиента:

`round(50 × recentDecisionMakers / decisionMakers + 30 × activeDepartments / departments + 20 × verifiedDecisionMakers / decisionMakers)`

Недавнее касание определяется выбранным периодом, проверка контактных данных — порогом API (сейчас 90 дней). При неизвестных ЛПР, отсутствии подразделений или пустой инициативе индекс не выставляется. В раскрываемом блоке видны формула и зоны внимания: один активный ЛПР, отсутствие недавних касаний, устаревшая проверка данных, неохваченные отделы и пробелы в истории. Неуказанные отделы отмечаются как ограничение расчёта. На срезе `backend/examples/coverage.json` индекс равен 80/100.

Отдельное демо карты в ветке `codex/croc-insight-frontend` остаётся самостоятельным прототипом. Основное приложение использует готовый API команды и не сохраняет правки в localStorage.
